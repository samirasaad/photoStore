# 📸 PhotoStore

**PhotoStore** is a React-based web application boilerplate for building photo gallery/store interfaces using modern frontend tools like **React**, **Redux**, and **SCSS**.

This project provides a solid foundation to manage photo assets, build UI components, connect to APIs, and scale with state management patterns.

integrated with unsplash for more premium quality images

it provides:
- viewing images according to authors
- search
- download image
- share image via social media
- see related to author images/collectins/likes

## 🚀 Features

- Built with **React**
- **Redux** for state management
- Modular folder structure
- SCSS support for styling
- Ready for API integration
- Responsive layout structure
- Ideal for photo gallery / store use cases

| Category           | Technology                   |

## 📂 Project Structure

```text
public/ # Static assets
src/ # Application source code
├── components/ # Reusable UI components
├── containers/ # Page or feature level views
├── redux/ # Redux store, actions, reducers
├── routes/ # App routing setup
├── scss/ # Global and component SCSS
├── utils/ # Helper utilities
├── index.js # App entry file
├── App.js # Main app container
.gitignore
package.json
README.md
```
